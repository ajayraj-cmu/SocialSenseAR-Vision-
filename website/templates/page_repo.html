AR CV Model Deployer

Paste your public GitHub repo and any required API keys.

Must be a public repo. The root should contain your CV model entry point.
One per line, format: KEY=VALUE. These are written to a .env file inside the deployed Modal container and passed as environment variables to your model.

Required for the SAM3 pipeline: OPENAI_API_KEY, GEMINI_API_KEY (or GOOGLE_API_KEY), HF_SAM_TOKEN (or HF_TOKEN).
